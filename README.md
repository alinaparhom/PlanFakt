# План / Факт

Единое адаптивное приложение для сайта и Telegram Mini App: ежедневные отчёты подрядчиков, месячные Excel-графики, план-факт, ресурсы, фотографии и архив версий.

## Запуск

```bash
npm install
cp .env.example .env
npm start
```

Откройте `http://localhost:3000`. Первый администратор создаётся автоматически:

- **ФИО:** Пархоменко Алина
- **логин:** `Пархоменко`
- **пароль:** `286`

После первого входа создайте объект, подрядчиков и пользователей. Рабочая база и файлы находятся в каталоге `data/` и не попадают в Git.

## Формат Excel

Приложение ищет строку с колонками **«Наименование работы»**, **«Подрядчик»**, **«Общий объём»**. Дневные колонки именуются, например, **«План 01.09»** и **«Факт 01.09»**. При выгрузке открывается сохранённый оригинал, суммы факта записываются в найденные ячейки, остальные листы и оформление остаются в книге.

## Telegram

Задайте `TELEGRAM_BOT_TOKEN` и публичный HTTPS-адрес `PUBLIC_URL`. Бот настроит кнопку Mini App. В карточке пользователя администратор должен указать его числовой Telegram ID; сервер проверяет криптографическую подпись `initData`.
