# План/Факт — Telegram Mini App

Приложение запускается как обычный сайт и как Telegram Mini App. Встроенный Node.js-сервер раздаёт интерфейс, отвечает на `/start` и `/app`, добавляет кнопку запуска под сообщением и настраивает кнопку меню бота.

## Подключение

1. В [@BotFather](https://t.me/BotFather) отзовите опубликованный токен командой `/revoke`, затем создайте новый через `/token`.
2. Разместите приложение на публичном адресе с HTTPS.
3. Скопируйте настройки и заполните их:

   ```bash
   cp .env.example .env
   ```

   ```env
   TELEGRAM_BOT_TOKEN=новый_токен_от_BotFather
   BOT_WEB_APP_URL=https://ваш-домен.example/
   PORT=3000
   ```

4. Запустите приложение:

   ```bash
   npm start
   ```

При старте бот автоматически регистрирует команды и кнопку меню. Файл `.env` исключён из Git, поэтому секрет не попадёт в репозиторий.

## Проверка

```bash
npm run check
curl http://localhost:3000/health
```
